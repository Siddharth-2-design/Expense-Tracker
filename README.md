# Expense-Tracker

A simple **Income and Expense Tracker** built with **HTML, CSS, and JavaScript**.

The project allows users to add their **earning and expense statements** and view them as financial records. It also calculates the total amount based on the added transactions.

## Features

* Add earning/income statements
* Add expense statements
* Display income and expense records
* Calculate total earnings
* View transaction details
* Simple user interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Purpose

This project was created to practice JavaScript concepts such as **DOM manipulation, event handling, functions, and dynamic element creation**.
